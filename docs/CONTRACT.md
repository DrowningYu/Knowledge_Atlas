# Implementation contract
Rust workspace: crates/atlas-core (SQLite/domain), crates/atlas-server (rmcp/Axum), src-tauri (desktop optional workspace member).
Core types serde snake_case, JSON shape:
Node {id,title,summary,explanation,status:'not_understood'|'learning'|'mastered'|'skipped',notes,collapsed:bool}
Edge {id,source,target,kind:'required'|'recommended'|'related',reason}. Direction source = concept, target = prerequisite. Required and recommended edges form DAG; related edges may cycle, exploration has path/depth guard.
Graph {id,title,root_id,version:u64,nodes:Node[],edges:Edge[],updated_at:string}
MapSummary {id,title,root_id,version,updated_at,node_count}
Patch {map_id,expected_version,operations:Operation[]}
Operation is internally tagged `op`: upsert_node {node:Node}; delete_node {node_id}; upsert_edge {edge:Edge}; delete_edge {edge_id}; rename_map {title}; set_root {node_id}.
All fields explicit. Stable IDs allow letters/numbers/underscore/hyphen (max 128). Reject dangling refs, duplicates, invalid statuses, self edges and dependency cycles. Deleting node removes incident edges; deleting root requires set_root in same patch. Atomic optimistic version check.
Core crate `atlas_core`: Store cloneable with synchronized SQLite connection, `Store::open(path) -> Result<Self>`; methods `list_maps()->Result<Vec<MapSummary>>`, `create_map(title:&str,target:&str)->Result<Graph>`, `get_map(id:&str)->Result<Graph>`, `get_node(map_id:&str,node_id:&str)->Result<Node>`, `apply_graph_patch(patch:Patch)->Result<Graph>`, `delete_map(id:&str,expected_version:u64)->Result<()>`, `undo(map_id:&str)->Result<Graph>`, `redo(map_id:&str)->Result<Graph>`, `restore_deleted_map()->Result<Graph>`, `import_graph(graph:Graph)->Result<Graph>` (validate new map ID, no overwrite), `export_outline(map_id:&str,format:&str)->Result<String>` formats markdown/mermaid/json, `recommend(map_id:&str)->Result<Vec<Node>>`, `seed_demo()->Result<Graph>` (idempotent pid-control). `subscribe()->tokio::sync::broadcast::Receiver<Change>`; Change {map_id,version,kind} emitted AFTER commit for all mutations incl undo etc.
Tauri command `api` args {method:string,params:object}; return JSON serializable object matching server dispatch. Desktop frontend uses invoke('api',{method,params}); listens `atlas-changed` payload Change. `connection_info` returns {url,token,port,running,last_seen,client_config}, token displayed only on demand; client_config native remote MCP JSON contains bearer header. No cloud requests.
Headless real Rust server exposes POST /api {method,params}, GET /events SSE Change (auth bearer header or fetch stream), GET /healthz (no secrets), /mcp official Streamable HTTP. All /api /events /mcp require Bearer token and strict allowed Origin (no Origin permitted for native clients, never wildcard/null). Allow only Tauri origins and explicit localhost Vite origin passed in args. Host must be loopback. Bind 127.0.0.1, default port 38473 or available port fallback for desktop. Max 2MB body.
Server `atlas_server::start(store:Store, options:ServerOptions)->Result<ServerHandle>` async. Options {port:u16,token:String,allowed_origins:Vec<String>}. Handle {port:u16,token:String,...}, methods info()->serde_json::Value and shutdown(). `dispatch(store:&Store,method:&str,params:Value)->Result<Value>` shared by Tauri / HTTP / tools. Server tools at least list_maps/create_map/get_map/get_node/apply_graph_patch/export_outline. Params matching method fields; create_map {title,target}; get_map {map_id}; get_node {map_id,node_id}; patch method params Patch directly; undo/redo/recommend {map_id}; delete_map {map_id,expected_version}; import_graph {graph}; export_outline {map_id,format} returns {text}. All results consistent JSON; list_maps array, map operations Graph, recommendations Node[]. MCP tools preserve errors as isError, optimistic conflicts identifiable.
Headless binary `atlas-server --db PATH --port PORT --token-file PATH --allow-origin ORIGIN`: tokenfile generated private if absent, stdout only URL + tokenfile path (not token), auto seed demo if empty. For browser dev query param #token=..., frontend stores only sessionStorage and erases hash; backend token not compiled. Desktop never needs Node at runtime.
Frontend adapter supports Tauri or browser development against http://127.0.0.1:38473 (VITE_ATLAS_API optional); uses same real SQLite Rust endpoints, no fake localStorage graph. /api errors {error:string}; client refresh on SSE or Tauri event; protect unsaved drafts/version conflict.
