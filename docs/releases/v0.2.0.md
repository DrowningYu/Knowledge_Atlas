# Knowledge Atlas 0.2.0

注册云端账号后，桌面 App 与插件读写同一份云端知识地图。插件不再要求个人电脑在线或在本机运行 tunnel。

- 注册、登录、退出与按账号隔离的数据存储
- App 每 5 秒检查云端更新；版本冲突不会覆盖未保存的编辑
- 本地模式继续可用；登录后可主动导入本机地图，原数据保留、同 ID 跳过，不迁移撤销历史
- ChatGPT 使用远程 MCP + OAuth 授权；支持 PKCE、刷新令牌、撤销插件授权
- 登录凭据仅保留当前 App 会话，重启后需重新登录；暂不提供自助密码找回

云端页面：https://littlefish.sarl/atlas/

插件地址：https://littlefish.sarl/atlas/mcp

ChatGPT 中添加远程 MCP，认证选 OAuth（客户端注册使用 DCR），用与 App 相同的知识地图账号登录授权。具体账号的 ChatGPT 可用入口及首次授权需要在该账号中完成。云端服务、OAuth 协议和 MCP 写入同步有自动测试，不能替代用户账号端验收。

旧版的本机 tunnel 是独立的本地连接，不会自动改写为云端。升级后请在 ChatGPT 重新添加上面的云端连接，停用旧连接。
