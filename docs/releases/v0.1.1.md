## Mac 首次打开

本版本使用 ad-hoc 签名，**尚无 Apple Developer ID 签名和公证**。这能验证应用包的完整性，但不代表 Apple 已认可其开发者。浏览器下载后仍可能被系统拦截。

确认下载来自本仓库，且 `SHA256SUMS.txt` 校验一致后，尝试打开应用，再到「系统设置 → 隐私与安全性」中为 Knowledge Atlas 选择「仍要打开」。如果仍出现“应用已损坏”，请保留准确提示并反馈，不要关闭整个系统的 Gatekeeper。

参考：[Tauri 的 ad-hoc 签名说明](https://v2.tauri.app/distribute/sign/macos/#ad-hoc-signing)、[Apple 的应用安全打开说明](https://support.apple.com/102445)。
