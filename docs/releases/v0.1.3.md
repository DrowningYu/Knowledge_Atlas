# Knowledge Atlas 0.1.3

把 ChatGPT 安全隧道集成到桌面应用，无需每天保持终端窗口。

- 设置页新增 ChatGPT 连接引导、隧道 ID 与运行密钥输入、连接状态、连接/断开/清除设置。
- 内置固定版本的 OpenAI 隧道运行程序，不依赖 Node 或单独安装 CLI。
- 支持系统凭据库保存密钥、下次打开应用自动连接、断线重连和进程异常退出后重启。
- 关闭窗口可留在菜单栏／托盘运行，可从菜单重新打开、断开或完全退出；退出会停止隧道。
- 本地 MCP 的认证保持启用；运行密钥不写入地图、JSON 设置或日志。

首次仍需在自己的 OpenAI 组织创建隧道、获取运行密钥，并在 ChatGPT 中绑定。电脑在线且应用运行时才能访问本地地图。教程见仓库 docs/chatgpt-background.md；账号端接入需在用户环境验证。

提供 Windows x64、macOS Apple Silicon / Intel、Linux amd64 安装包。macOS 应用使用 ad-hoc 签名封装，不含 Apple Developer ID 公证；沿用先前安装说明。
