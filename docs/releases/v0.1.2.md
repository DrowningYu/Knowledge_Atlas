# Knowledge Atlas v0.1.2

- 地图列表右键菜单：打开、重命名、导出 JSON、删除；删除可确认、取消或恢复，操作针对右键所选地图。
- 知识点右键菜单：详情、展开/收起、学习状态、复制 AI 提问、删除；学习目标不可删除。
- 画布右键菜单：适应画布、收起全部、撤销、重做。菜单支持方向键、Escape、点击外部关闭，并避开窗口边缘。
- 再次点击已展开的列表项或箭头会收起后续分支；切换同级分支仍保持面板位置。
- 左上角书本去除蓝色圆角底，图标与标题垂直居中。

## Mac 首次打开

替换旧应用后启动，现有本地数据库保留。Mac 安装包沿用完整 ad-hoc 签名和拖入 Applications 的 DMG 布局，尚无 Developer ID 公证。如 macOS 阻止首次运行，在系统设置 → 隐私与安全性中允许打开。

## 验证

真实 Rust/SQLite 服务配合 Chromium 验证展开/重复点击收起、右键非当前地图的重命名和删除、取消与恢复、根节点保护、MCP 更新同步及既有导出等流程。发布工作流继续验证四种安装包，Mac 两架构检查最终 DMG 签名和原生启动。

ChatGPT 插件在独立的 `chatgpt-plugin` 分支提供；应用本身不要求安装插件。
